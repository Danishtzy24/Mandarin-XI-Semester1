Pengetahuan umum Tiongkok

Tiongkok dan istilah dasar.

Tiongkok atau 中国 (Zhōngguó) adalah negara di Asia Timur dengan ibu kota Beijing. Bahasa Mandarin merupakan bahasa nasional Republik Rakyat Tiongkok dan termasuk salah satu dari enam bahasa resmi/internasional yang diakui PBB.

Pola kalimat penting

Pola tanya dan jawab.

Menanyakan kabar

Subjek + 好 + 吗？
你好吗？Nǐ hǎo ma?Kamu apa kabar?
爸爸好吗？Bàba hǎo ma?Ayah apa kabar?

吗 (ma) biasanya berada di akhir kalimat pertanyaan.

Menjawab kabar

Subjek + 很好
我很好。Wǒ hěn hǎo.Saya baik-baik saja.
她们很好。Tāmen hěn hǎo.Mereka sangat baik.

Mengatakan “juga”

Subjek + 也 + 很好
我也很好。Wǒ yě hěn hǎo.Saya juga baik.
我们也很好。Wǒmen yě hěn hǎo.Kami juga baik.

Bertanya balik

Subjek + 呢？
你呢？Nǐ ne?Bagaimana denganmu?
老师呢？Lǎoshī ne?Bagaimana dengan guru?
Ingat: 吗 (ma) digunakan untuk pertanyaan, sedangkan 呢 (ne) digunakan untuk bertanya balik “bagaimana dengan...?”.

你叫什么名字？ (Nǐ jiào shénme míngzi?) = “Siapa namamu?”.

A. Kosakata baru

HanziPinyinArti / fungsi
叫jiàobernama; dipanggil
什么shénmeapa
名字míngzinama
哥哥gēgekakak laki-laki

两liǎngdua, dipakai untuk menyebut jumlah sebelum kata satuan

B. Pola bertanya nama dan menyebut keluarga

Menanyakan nama

Subjek + 叫什么名字？
你叫什么名字？Nǐ jiào shénme míngzi?Siapa namamu?
你妹妹叫什么名字？Nǐ mèimei jiào shénme míngzi?Siapa nama adik perempuanmu?

Menyebut nama

Subjek + 叫 + nama
我叫大卫。Wǒ jiào Dàwèi.Nama saya David.
我爸爸叫阿里。Wǒ bàba jiào Ālǐ.Ayah saya bernama Ali.

Menghitung dengan 个

Angka + 个 + orang/benda
一个妹妹Yí ge mèimeisatu orang adik perempuan
三个哥哥Sān ge gēgetiga orang kakak laki-laki

Memakai 两 untuk jumlah “dua”

两 + 个 + kata benda
我有两个弟弟。Wǒ yǒu liǎng ge dìdi.Saya mempunyai dua adik laki-laki.
二 (èr) untuk angka/urutan; 两 (liǎng) sebelum kata satuan untuk menyatakan jumlah.

C. Menyatakan punya/tidak punya dan menghubungkan benda

Subjek + 有 + benda/orang我有一个姐姐。Wǒ yǒu yí ge jiějie.Saya punya seorang kakak perempuan.
Subjek + 没有 + benda/orang我没有哥哥。Wǒ méiyǒu gēge.Saya tidak punya kakak laki-laki.
Subjek + 有 + benda + 吗？你有妹妹吗？Nǐ yǒu mèimei ma?Apakah kamu punya adik perempuan?
Kata benda + 和 + kata benda爸爸和妈妈Bàba hé māmaAyah dan ibu

Contoh tambahan: 他有两个姐姐。 Tā yǒu liǎng ge jiějie. (Dia punya dua kakak perempuan); 他有两个妹妹。 Tā yǒu liǎng ge mèimei. (Dia punya dua adik perempuan); 她没有妹妹。 Tā méiyǒu mèimei. (Dia tidak punya adik perempuan).

B. Pola kalimat

Menyatakan profesi/identitas

Subjek + 是 + profesi
我们是学生。Wǒmen shì xuésheng.Kami adalah siswa.

Menyatakan “bukan”

Subjek + 不是 + profesi
我不是职员。Wǒ bú shì zhíyuán.Saya bukan pegawai.

Bertanya ya/tidak

Subjek + 是 + profesi + 吗？
你是老师吗？Nǐ shì lǎoshī ma?Apakah kamu seorang guru?

Mengatakan “semua”

Subjek + 都 + 是/不是 + profesi
我们都是学生。Wǒmen dōu shì xuésheng.Kami semua adalah siswa.
他们都不是警察。Tāmen dōu bú shì jǐngchá.Mereka semua bukan polisi.
我们是学生。Wǒmen shì xuésheng.Kami adalah siswa.
我是医生。Wǒ shì yīshēng.Saya adalah dokter.
他不是警察。Tā bú shì jǐngchá.Dia bukan polisi.

也 dan 都 berada sebelum 是/不是: 我们也都是学生。 (Wǒmen yě dōu shì xuésheng.) = “Kami juga semuanya siswa.”

Pinyin & nada

Nada: ā datar, á naik, ǎ turun-naik, à turun. Nada dapat mengubah arti.

Percakapan dasar

你好 (nǐ hǎo) = halo; 你好吗？ (nǐ hǎo ma?) = apa kabar?; 我很好 (wǒ hěn hǎo) = saya baik; 你呢？ (nǐ ne?) = kalau kamu?

Identitas & jumlah

我叫… = nama saya…; 有 / 没有 = punya / tidak punya; 是 / 不是 = adalah / bukan; 都 = semua; 你是哪国人？ = kamu orang negara mana?
