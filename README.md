# Bahasa Mandarin — materi pemula

Situs materi Mandarin yang disusun dari enam dokumen: salam, kabar, angka, nama dan keluarga, profesi, serta asal negara. Materi disertai Hanzi, pinyin, arti, contoh, latihan per topik, dan latihan campuran.

Buka `index.html` langsung di browser atau unggah seluruh isi folder ini ke hosting statis. Tidak ada instalasi atau proses build. Ikon Lucide dimuat dari CDN; jika CDN tidak tersedia, ikon garis cadangan tetap ditampilkan. Tautan PDF sumber memerlukan koneksi internet dan izin Google Drive.

Jawaban dan nilai latihan disimpan di penyimpanan browser pada perangkat yang digunakan, jika penyimpanan tersedia.
